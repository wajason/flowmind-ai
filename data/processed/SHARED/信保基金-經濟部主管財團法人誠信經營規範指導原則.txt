# `經濟部主管財團法人誠信經營規範指導原則總 說明`

```
財團法人法業經總統於一百零七年八月一日公布，並自公布日後
六個月施行，為指導財團法人訂定誠信經營規範，建立良好組織運作
架構，爰依據財團法人法第二十四條第三項，擬具「經濟部主管財團
法人誠信經營規範指導原則」(以下簡稱本原則)，全文共六點，其重
點如下：
```

- `一、本原則授權依據。(第一點)`

- `二、適用本原則之財團法人。(第二點)`

- `三、禁止董事、監察人、執行長與該等職務之人或其他從業人員從事 不誠信行為。(第三點)`

- `四、董事、監察人、執行長與該等職務之人、其他從業人員或利害關 係人之利益衝突迴避事宜。(第四點)`

- `五、誠信經營規範應包含之內容。(第五點)`

- `六、財團法人宜設專責單位推動誠信經營之相關事宜。(第六點)`

```
第一頁/共三頁
```

## <u>`經濟部主管財團法人誠信經營規範指導原則`</u>

|`規    定`|`說    明`|
|---|---|
|`一、本原則依財團法人法（以下簡稱本法）`<br>`第二十四條第三項訂定之。`|`本指導原則之授權依據。`|
|`二、經濟部`(`以下簡稱本部`)`主管財團法人`<br>`符合本部依本法第二十四條第三項`<br>`所定在法院登記財產總額或當年度`<br>`收入達一定金額者（以下簡稱財團法`<br>`人），應參照本原則訂定誠信經營規`<br>`範。`|`依財團法人法第二十四條第二項及第三`<br>`項規定，一定規模以上之財團法人應參照`<br>`本原則訂定誠信經營規範，該一定金額依`<br>`據經濟部主管財團法人管理監督作業辦`<br>`法第五條規定，係指法院登記之財產總額`<br>`達新臺幣一億元或年度收入總額達新臺`<br>`幣三千萬元以上。`|
|`三、財團法人之董事、監察人、執行長與`<br>`該等職務之人或其他從業人員，於執`<br>`行業務之過程中，不得直接或間接提`<br>`供、承諾、要求或收受任何不正當利`<br>`益，或做出其他不法或違背受託義務`<br>`等不誠信行為。`|`明定禁止不誠信行為。相關用語則參照財`<br>`團法人法第十五條、第十六條所稱執行長`<br>`與該等職務之人、第五十三條所稱其他從`<br>`業人員等。`|
|`四、財團法人之董事、監察人、執行長與`<br>`該等職務之人、其他從業人員或利害`<br>`關係人，於出、列席董事會時，對董`<br>`事會所列議案，有利益衝突者，應說`<br>`明其重要內容。`<br>`上開人員於該議案討論及表決`<br>`時，應自行迴避，且不得代理其他董`<br>`事。董事間應自律，不得不當相互支`<br>`援。`|`依據財團法人法第十五條規定，董事、監`<br>`察人、執行長與該等職務之人執行職務`<br>`時，有利益衝突者，應自行迴避。為加強`<br>`利益衝突迴避之規範，故明定上開人員、`<br>`其他從業人員及利害關係人，於出、列席`<br>`董事會時，對董事會所列議案，有利益衝`<br>`突者，應說明其重要內容並應於該議案討`<br>`論及表決時自行迴避。`|
|`五、財團法人訂定之誠信經營規範，應包`<br>`含下列規定：`<br>`（一）依業務性質，明定行為指南及`<br>`不誠信行為之具體範圍，並就`<br>`行賄及收賄、提供非法政治獻`<br>`金、不當慈善捐贈或獎助、提`<br>`供或接受不正當利益、侵害智`<br>`慧財產權及利益衝突等行`<br>`為，訂定防範之作法。`<br>`（二）建立違反誠信經營規範之懲`<br>`戒及申訴制度。`<br>`（三）建立並公告財團法人內部檢`|`一、財團法人應本於誠信經營，除依據財`<br>`團法人法第十四條至第十七條、第二`<br>`十一條、第二十二條與第五十四條等`<br>`規定及相關法令規定辦理外，並應將`<br>`重要項目訂定於誠信經營規範，以利`<br>`執行。`<br>`二、為加強落實誠信經營規範，財團法人`<br>`應建立懲戒、申訴、檢舉及調查等機`<br>`制，並對檢舉人妥為保護及獎勵。`|
